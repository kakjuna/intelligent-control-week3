     ANALISIS dan DISKUSI
     Pada percobaan minggu ke-3 ini, saya melakukan uji coba mendeteksi objek menggunakan deep learning dan teknologi night vision. Saya menggunakan Convolutional Neural Network (CNN) sebagai model klasifikasi gambar untuk mengenali kategori objek yang tertangkap kamera. Selain itu, saya juga memanfaatkan TensorFlow untuk membuat dan menjalankan model CNN tersebut.Proses pengembangan program ini dibagi menjadi dua bagian dengan format yang berbeda. Program pertama menggunakan format Jupyter Notebook (ipynb), yang digunakan untuk membuat dan melatih CNN agar mampu melakukan klasifikasi objek. Program kedua dalam format Python script (py) digunakan untuk klasifikasi objek secara real-time dari kamera, dengan tambahan fitur night vision.Saat program dijalankan, dua frame yang berbeda dihasilkan. Frame utama menampilkan video langsung dari kamera, di mana program akan mengklasifikasikan objek berdasarkan prediksi model CNN. Jika objek berhasil dikenali, nama kelas objek tersebut akan muncul pada frame utama. Sedangkan frame kedua menampilkan video dalam mode night vision, yang memberikan alternatif tampilan dalam kondisi cahaya rendah. Frame night vision ini tidak digunakan untuk klasifikasi objek, melainkan untuk meningkatkan visibilitas di situasi kurang cahaya.
